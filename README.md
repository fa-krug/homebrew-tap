# fa-krug Homebrew tap

Homebrew formulae for [fa-krug](https://github.com/fa-krug) projects.

```sh
brew install fa-krug/tap/zubi
```

| Formula | What it is |
| --- | --- |
| `zubi` | The command-line client for [Zubi](https://fa-krug.github.io/zubi/): read and edit the Reminders, calendars and Notes a Mac running Zubi shares. macOS and Linux. |

The formulae are written by each project's release workflow; changes made here by hand are
overwritten by the next release. Report problems in the project's own repository, for example
[fa-krug/zubi](https://github.com/fa-krug/zubi/issues).
